# 農業部統計處－農業統計業務查詢 操作說明

## 網站層級（由上而下）

```
農業部統計處  https://agrstat.moa.gov.tw/moasdweb/Default.aspx
├─ 統計查詢
│   ├─ 農業統計業務查詢  inquire/InquireAdvance.aspx?qcode={qcode}   ★本目錄涵蓋範圍（207 表）
│   ├─ 農產品貿易資料查詢  common/SubMenu.aspx?menu=INQ_TRADE
│   ├─ 公務報表查詢        inquire/AdminStat.aspx
│   └─ 重要統計指標        inquire/Indicator.aspx
├─ 調查總覽（主力農家所得／農業固定資本形成／養豬頭數／畜禽統計）
├─ 統計分析及書刊（統計書刊、統計分析、統計視覺化專區）
└─ 統計服務（下載區、環境與經濟帳、線上學習、資料填報）
```

## qcode 編碼

第 1 碼＝統計類別，第 2 碼＝次類別，後 2 碼＝流水號。**沒有 G 類**。

| 碼 | 類別 | 表數 |
|---|---|---|
| A | 農地環境統計 | 14 |
| B | 農民(農戶)統計 | 25 |
| C | 農業生產統計 | 98 |
| D | 農業經營統計 | 18 |
| E | 農業生產資材與設備統計 | 15 |
| F | 糧食供需統計 | 7 |
| H | 其他農業統計 | 30 |

左側選單只會展開「目前 qcode 所屬的那一大類」，所以要取得完整目錄必須逐個大類各開一頁
（`AA01 / BA01 / CA01 / DB01 / EA01 / FA01 / HA01`）再解析 `.MenuLink`。

## 查詢頁操作

1. **統計期間**：`ddlYearBegin` ~ `ddlYearEnd`（民國年，預設已是近 11 年；資料最早可到 41 年）
2. **統計量**：勾選要查的數量欄（如「耕地面積」「家畜飼養頭數」）
3. **複分類**：每個維度按「選擇」開 modal，modal 內用左側頁籤切換維度，可「全選」；最後按「確定」
4. 上限 15,000 儲存格（頁面會即時顯示已選取數）
5. 按「查詢」在同頁下方輸出交叉表

頁面用 ASP.NET UpdatePanel + 加密 hidden field（`hidInquireGroup`／`hidCode`），**不建議用 requests 復刻**，
請直接用瀏覽器操作；本專案的取數是以瀏覽器 JS 點選完成的（見 `案件/嘉義農再/取數紀錄.md`）。

## 口徑與陷阱

- **只到縣市層級**，沒有鄉鎮別。要鄉鎮別請改查各縣市主計處資料庫。
- 精度保留小數 2 位，適合直接抄進計畫書。
- `AB04 水產養殖面積` 的「養殖期別」維度只有 `養殖合計 / 單養 / 混養`，其中 `養殖合計 = 單養 + 混養`，
  **沒有更上層的總計**。此口徑比《嘉義縣統計年報》的養殖面積少約 125 公頃（113 年：6,635.18 vs 6,760.73，
  差額全在內陸養殖），兩者不可混用。
- `CD01 家畜飼養場數及頭數` 的家畜別只有 **豬／牛／羊** 三種，沒有鹿、馬，也沒有合計；
  需要「合計／豬／羊／牛／鹿／馬」完整欄位時要查縣統計年報（主計處資料庫）。
- 部分格子為 `…`（無資料或不適用）。
