## 選用原則

1. **要寫進書件的縣內數字 → 走該縣市主計處的「公務統計報表查詢」**（有鄉鎮／行政區別又有原始小數）。
   資料庫查詢平台把小數四捨五入掉了，只適合快速看趨勢。
2. **跨縣市比較／全國序列 → 農業部統計處（02）**。
3. **鄉鎮×作物 → 農糧署農情報告（04）**，其他來源都做不到這個解析度。
4. **水產養殖、畜牧的鄉鎮／行政區別 → 只有縣市統計年報有**（嘉義 01、臺南 06）；
   農業部、漁業署、公務統計報表都只到縣市或全市。
5. **同一張表不可混用來源**。各來源口徑不一定相同，混用會被審議委員抓（見各節點「口徑與陷阱」）。
6. 農糧署與縣市農業局數字不一致時，本專案案件**以農業局年報為準**（2026-09-19 使用者指示）。

## 跨來源已知口徑地雷

| 地雷 | 說明 |
|---|---|
| 農業部統計處 `AB04` 水產養殖面積 | 「養殖合計」**不含休養**，比漁業署／縣市統計年報的「總計」少一截（嘉義縣 113 年少 125.55 公頃） |
| 氣象署官方平年值 vs CODiS 自行重算 | 官方對缺測做過補遺，溫度差 ≤0.2℃ 可忽略，**降水量差很明顯**（臺南 1991-2020 年雨量中位數：官方 1,766.8 vs 純 CODiS 1,691.4） |
| 氣象署「最高溫度」 | 是**月平均最高氣溫**，不是月極端最高氣溫，兩者差 3℃ 以上 |

## 新增來源的標準流程

1. 拿到深層網址 → 往上找平台入口（麵包屑／logo／網站導覽）。
2. 列舉分類代碼，把**整棵目錄樹**存成 `目錄.md`（人看）＋ `目錄.json`（程式用）。
   - 主計處系統（嘉義、臺南同款）：`python scripts/dgbas_statfile_tree.py <base> <CateNo> <輸出檔名>`
   - 農業部：左側選單只展開當前大類 → 每個大類各開一頁（`AA01/BA01/CA01/DB01/EA01/FA01/HA01`）
3. 寫 `操作說明.md`，務必記錄：**網站層級、查詢頁操作、空間解析度／精度／最新年度／與其他來源的差異**。
4. 能 script 化的放 `scripts/`。
5. **回來這一頁補一列。**
