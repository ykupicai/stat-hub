# 05 交通部中央氣象署－觀測資料查詢服務（CODiS）＋氣候月平均

計畫書「氣候」一節（氣溫／雨量／日照）的權威來源。**氣象署有兩套東西，用途完全不同，不可混用。**

## 網站層級

```
交通部中央氣象署 https://www.cwa.gov.tw
├─ 氣候 → 氣候統計 → 氣候月平均      https://www.cwa.gov.tw/V8/C/C/Statistics/monthlymean.html
│   └─ 官方「30 年平年值」，目前是 1991~2020，每 10 年更新一次（下一版 2001~2030，2031 年初才發布）
└─ 觀測資料查詢服務（CODiS）          https://codis.cwa.gov.tw/StationData
    └─ 逐站逐時／逐日／逐月原始觀測值，可拉到最新年度
```

## A. 氣候月平均（官方平年值）－ 用來核對，不能用來更新年度

頁面用 AJAX 取靜態 MOD 片段，**可直接抓**（免帳號、免 JS）：

```
https://www.cwa.gov.tw/V8/C/C/Statistics/MonthlyMean/MOD/Taiwan_{item}.html
```

`{item}` 代碼（從查詢頁 `<select id="Item">` 列舉）：

| 代碼 | 項目 | 代碼 | 項目 |
|---|---|---|---|
| `tx` | 氣溫 | `precp` | **降水量（平均）** |
| `meantxmax` | 最高氣溫 | `precp-median` | **降水量（中位數）** |
| `meantxmin` | 最低氣溫 | `precpday` | 降水量>=0.1mm日數 |
| `sunshine` | 日照時數 | `txmaxge30day` | 最高氣溫>=30℃日數 |
| `stnpres` | 測站氣壓 | `txminle10day` | 最低氣溫<=10℃日數 |
| `rh` | 相對濕度 | `txge25day` | 氣溫>=25℃日數 |
| `ws` | 風速 | `CamtMean` | 雲量 |

回傳是 HTML 表格，每列一個測站（第一欄站名，後接 12 個月 + 平均 + 統計期間）。
**首次請求可能 403**，先 GET 一次 `monthlymean.html` 取 cookie，再帶
`Referer` 與 `X-Requested-With: XMLHttpRequest`，失敗就 sleep 3 秒重試。

## B. CODiS API（用來更新到最新年度）

```python
POST https://codis.cwa.gov.tw/api/station
data = {"date":"2020-01-01T00:00:00", "type":"report_year",
        "stn_ID":"467410", "stn_type":"cwb", "more":"", "start":"", "end":""}
verify=False, Referer: https://codis.cwa.gov.tw/StationData
```

- **`type=report_year` 回傳的是「該站建站至今的全部逐月統計」**，不是某一年。
  臺南站一次回 1557 筆（1897-01 ~ 迄今），`date` 參數不影響回傳範圍。
- `type=report_month` 回的是**逐日**資料（365 筆），不要被名稱騙了。
- 擷取器：`scripts/cwa_codis_fetch.py`；期間統計：`scripts/cwa_climate_period_stats.py`

### 欄位口徑對應（已驗證與官方平年值同口徑）

| 書件欄位 | CODiS 欄位 | 彙整方式 |
|---|---|---|
| 最高溫度 | `AirTemperature.MeanDailyMaximum` | 各年同月值取**平均** |
| 平均溫度 | `AirTemperature.Mean` | 各年同月值取**平均** |
| 最低溫度 | `AirTemperature.MeanDailyMinimum` | 各年同月值取**平均** |
| 降水量 | `Precipitation.Accumulation` | 各年同月值取**中位數**（或平均，看書件註記） |
| 日照時數 | `SunshineDuration.Total` | 各年同月值取**平均** |
| 全年（溫度） | — | 12 個月值再平均 |
| 全年（降水量） | — | **各年年總雨量的中位數**，不是各月中位數相加 |

## 口徑與陷阱

1. **「最高溫度」是月平均最高氣溫，不是月極端最高氣溫。**
   `MeanDailyMaximum`（臺南 7 月約 33℃）≠ `Maximum`（月極端，臺南 7 月可到 36℃）。
   兩者差 3℃ 以上，拿錯欄位圖表會整組偏高。
2. **降水量官方同時公布「平均」與「中位數」兩套，數字差很多**
   （臺南 8 月：平均 466.1 mm vs 中位數 315.9 mm）。書件沿用哪一套要看原表註記，不可中途換。
3. **全年降水量欄不是各月加總**：
   - 「平均」表的全年 = 各月平均之和（臺南 1991-2020 = 1,760.6）
   - 「中位數」表的全年 = 年總雨量的中位數（臺南 1991-2020 = 1,766.8），
     各月中位數相加只有 1,313.6，差很大。
4. **官方平年值對缺測做過補遺，自行用 CODiS 重算不會完全相同。**
   溫度差 ≤0.2℃ 可忽略；**降水量差很明顯**（臺南 1991-2020 年雨量：官方中位數 1,766.8，
   純 CODiS 重算僅 1,691.4）。書件若已引用官方平年值，改用 CODiS 重算時要在註記寫明統計期間與來源。
5. **測站會有長期缺測**。臺南站（467410）**1998 年 5 月 ~ 2001 年 12 月全項目缺測（44 個月）**，
   統計時必須排除，否則年總雨量會被當成 0 而嚴重低估。跑新站前一定先做缺測盤點。
6. 平年值**每 10 年才更新一次**，所以委員說「氣候資料停在 2020 太久」時，
   官方沒有現成的新平年值可抄，只能自己用 CODiS 重算並標明統計期間。
7. 政府網站憑證缺 Subject Key Identifier，`requests` 一律 `verify=False`。

## 空間解析度／精度／最新年度

| 項目 | 內容 |
|---|---|
| 空間解析度 | **測站**（非鄉鎮、非縣市）。臺南平地＝臺南站 467410；嘉義＝嘉義站 467480 |
| 精度 | 溫度、日照小數 1 位；降水量小數 1 位 |
| 最新年度 | 逐月觀測值更新至當月（本次取數時已有 2026-09） |
| 與其他來源差異 | 縣市統計年報的氣候表多半轉載自氣象署同一測站，但常只到前一年 |
