# 09 行政院主計總處－三大普查動態查詢系統

普查類數字（農牧業家數、農林漁牧業從業人口、企業單位數、常住人口……）的權威來源，**可細到鄉鎮別**。

## 網站層級

```
三大普查統計資料查詢首頁  https://dtable.dgbas.gov.tw/censuall/webMain.aspx?sys=100&funid=defjsp
├─ 三大普查動態查詢系統   webMain.aspx?sys=210&x=2098&funid=advqry      ★ 本節點
├─ 人口及住宅普查統計表   https://www.stat.gov.tw/News.aspx?n=2755&sms=11065（靜態報表）
├─ 農林漁牧業普查統計表   https://www.stat.gov.tw/News.aspx?n=2763&sms=11069
└─ 工業及服務業普查統計表 https://www.stat.gov.tw/News.aspx?n=2740&sms=11059
```

可查普查：人口及住宅 89／99／109、農林漁牧業 94／99／104／109、工業及服務業 95／100／105／110。
統計項 342 個（農林漁牧 178、工商 129、人口 35）、複分類 351 組，完整清單見 `目錄.md`／`結構.json`。

## 頁面操作（人工）

選普查年度 → 從左側樹把「統計項」拖到統計項欄 → 把「表頭／表側」複分類拖到對應欄 → 查詢。
輸出可選網頁／Excel／CSV／ODS／PDF。一次最多 10 個統計項、3 組複分類。

## 程式取數（`stat_mcp/census.py`，2026-10-07 實測）

1. 主頁 HTML 內嵌全部 metadata：`gfld`（統計項樹）、`gcode1`（複分類與選項）、`clsfld`（各普查別統計項代碼範圍：1 人口 231…、2 農林漁牧 211000000-216999000、3 工商 221…229）。
2. 統計項節點後面接數個「變體」（attr1≥5），各有不同 `fldid` 與 `codetype`（可搭配的複分類 fldid）；**要選 codetype 涵蓋所選複分類的那個變體**。
3. 查詢條件字串（`&fldlist=[fldid!名稱|] ] &codelist=[分類fldid!名稱!選項val!選項名…|] …`，`&` 換成 `@26@`、每 1024 字一段）
   POST 到 `webMain.aspx?sys=601&x=2489&setid=<session>`，再 GET `webQuery.aspx?sys=253&m02=stm08&funid=advqry&sesid=<session>`。
4. 結果以 `var gData=[{統計期, area, 鄉鎮別, 統計項…}]` JSON 內嵌於回傳頁，數值為含千分位的字串。

CLI：`python stat_mcp/census.py crawl`（重建結構）、`python stat_mcp/census.py 109農林漁牧 農牧業普查家數 鄉鎮別`。
MCP：`stat_census_items` → `stat_census_query`（預設入庫 `資料庫/stat.sqlite`，dataset_id `census:<hash>`）。

## 口徑與陷阱

- **普查 5 年一次**（人口普查 10 年）：農林漁牧業最新 109 年、工商 110 年；114 年基準普查約 116–117 年公布。書件引用要註明普查年。
- 同名統計項在不同普查年度可能屬不同變體（代碼範圍不同），程式依普查別的 `clsfld` 範圍挑選。
- 「鄉鎮別」與「縣市別」的分類 fldid 相同（320011000），差別在分類名稱；工商普查另有 321011000 一組。
- ⚠ **不是每個統計項都有鄉鎮別**：例「農事及畜牧服務業普查家數」只有縣市別。單查時網站回 0 列；**和其他項一起查時，該項整欄被補 0 而不報錯**。
  `census.query` 已加偵測（回傳 warnings，MCP 工具遇警告不入庫）。`結構.json` 的「可搭配複分類」因縣市別／鄉鎮別共用代碼 320011000，無法精確區分。
- **動態查詢查不到的鄉鎮別（如農事及畜牧服務業）改用靜態「普查結果統計表」**：統計資訊網 › 農林漁牧業普查 › 統計表 › 各年普查結果統計表 › **按縣市別**（每縣市約 40 張 ODS／XLSX），
  其中「表1 農林漁牧業普查統計結果摘要」一張就有各區的農牧業／農事及畜牧服務業／林業／漁業家數。數字以空白為千分位（`3 534`），「-」＝0。
- 驗證（2026-10-07）：臺南農再表4-7 以動態查詢 230 格、靜態統計表 304 格雙來源回測全部相符（見 `案件/臺南農再/取數紀錄.md`）；109 年農林漁牧業普查「農牧業普查家數」鄉鎮別 368 列，與網頁查詢結果一致。
