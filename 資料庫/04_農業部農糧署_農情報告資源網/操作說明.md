# 農業部農糧署－農情報告資源網 操作說明

## 為什麼需要它

它是**唯一公開、可查到「各鄉鎮 × 各作物」收穫面積與產量**的來源。
農業部統計處只到縣市別；嘉義縣公務統計報表只有「主要作物」（少數幾種）；
《嘉義縣統計年報》表4-3／4-4 有鄉鎮別但最新只到 113 年——本站已有 **114 年**。

## 入口與網址

```
農情報告資源網  https://agr.afa.gov.tw/afa/afa_frame.jsp   （frameset）
├─ 選單          afa_menu.jsp
└─ 作物（非稻作）
    ├─ 鄉鎮作物查詢        pgcroptown_cond.jsp → 結果 pgcroptown.jsp   ★ 本專案使用
    ├─ 縣市作物查詢        pgcropcity_cond.jsp
    ├─ 作物比較            pgcropcomp_cond.jsp
    ├─ 面積產量查詢        pgcropmeaqty_cond.jsp / pgcropmeaqty_all_cond.jsp
    ├─ 重要作物產量        pgcropsigqty_cond.jsp
    └─ 生產面積 / 生產作物  pgprodmea_cond.jsp / pgprodcrop_cond.jsp
└─ 稻作 pgricetown_cond.jsp 等同組查詢
```

## 查詢參數（POST 到 pgcroptown.jsp）

| 欄位 | 說明 |
|---|---|
| `accountingyear` | 民國年，086～114 |
| `item` | 期作別：00 裡作／01 一期作／02 二期作／**03 全年作** |
| `corn001` | 作物類別：01 雜糧／02 蔬菜／03 果品／04 牧草／05 特用作物／06 花卉／07 綠肥／08 其他 |
| `crop` | **作物代號，必填**（沒有「類別合計」選項） |
| `city` | 縣市代號，嘉義縣＝`0010` |
| `btnSend` | `送　出` |

作物代號清單可用 AJAX 取得（不必解析 HTML）：

```
https://agr.afa.gov.tw/afa/ajax/jsonAfaCode1.jsp?corn001={類別}&input803=
```

回傳欄位：`縣市鄉鎮名稱 / 種植面積 / 結實面積 / 每公頃收量 / 收量`，最後一列是「合 計」。
**「結實面積」＝統計年報的「收穫面積」；「收量」單位是公斤。**

## 口徑與陷阱

- **沒有「類別合計」**，要類別總量必須把該類別所有作物代號逐一查完再加總
  （雜糧 19、蔬菜 87、果品 55、特用作物 47 個代號）。
- **蔬菜類含菇類（951～970）**，其「面積」是太空包／段木栽培量，加總會爆掉（113 年 57,759 vs 實際 14,213 公頃）。
  **要對上統計年報就必須剔除 951 以後的代號。**
- **沒有製糖甘蔗**。特用作物類只有 306 生食甘蔗；製糖甘蔗由臺灣糖業公司提供，
  只出現在《嘉義縣統計年報》表4-4(2) 與農業部統計處 `CC05`，而 `CC05` 的年度標示**落後一年**
  （其「114年」值＝統計年報的 113 年值），所以 114 年期製糖甘蔗目前無處可查。
- 稻作不在此查詢（另有 pgrice* 系列）；本專案的稻米改用嘉義縣公務統計報表 `20321-02-01`。
- 頁面是 frameset + 自我 POST，用 requests 直接 POST 到 `pgcroptown.jsp` 即可（先 GET 一次 `_cond.jsp` 拿 session）。

## 回測驗證（113 年 vs 嘉義縣統計年報表4-4）

| 類別 | 本站加總 | 統計年報 | 判定 |
|---|---|---|---|
| 雜糧 | 9,680.63 公頃 / 50,852.09 公噸 | 9,680.58 / 50,852.01 | ✔ |
| 蔬菜（剔除菇類） | 14,213.15 / 190,692.57 | 14,213.20 / 190,692.65 | ✔ |
| 果品 | 18,375.05 / 200,363.18 | 18,375.05 / 200,363.18 | ✔ |
| 特用作物 | 2,768.69 / 5,990.75 | 4,524.46 / 146,715.44 | ✘ 差額＝製糖甘蔗 |

柑橘類需自行彙總代號 603～618（113 年縣合計 52,082.47 公噸，與統計年報一致）。

## 程式取數

`scripts/afa_harvest.py`：讀 `afa_crop_codes.json`，逐作物查嘉義縣、輸出 `afa_data.json`
（結構：`{年度: {類別: {作物代號: {name, rows: {鄉鎮: [結實面積, 收量公斤]}}}}}`）。
208 個作物 × 2 年約 7 分鐘，建議背景執行。
