# 08 政府資料開放平臺（data.gov.tw）－案件用過的單一資料集

不是整座查詢平台，而是**案件裡實際取用過的個別資料集**登記處。
每筆記下資料集編號、正式名稱、提供機關、更新頻率與已知陷阱，下次要用直接照編號回查。

平台入口：<https://data.gov.tw>
資料集頁網址規則：`https://data.gov.tw/dataset/<編號>`
Metadata API（免帳號）：`https://data.gov.tw/api/v2/rest/dataset/<編號>`

臺東 2、苗栗 2、彰化 2、屏東 1、高雄 1、桃園 1、新竹縣 1。

**陷阱**：
1. `Fiscal_Year` 是西元，書件用民國年，務必換算。
2. **罕用字在原始檔已遺失**：官田區那筆 `Construction_Name` 為 `瓦?`（第二字是半形問號 U+003F）。
   本專案依官田區「瓦磘里」地名補正為「瓦磘」，並在書件資料來源加註；**正確用字仍待地政單位覆核**。
3. 檔案編碼為 UTF-8 with BOM，`csv.DictReader` 請用 `encoding='utf-8-sig'`。
4. 下載直鏈在 `opdadm.moi.gov.tw`，會隨改版變動；要程式化下載請先打 metadata API
   取 `distribution[].resourceDownloadUrl`，不要寫死。
