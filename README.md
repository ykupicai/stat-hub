# 統計資料庫專案

彙整案件實際用過的統計資料庫網址，並把每個資料庫「爬到最上層」後的完整目錄結構留存下來，
之後任何案件要更新統計圖表時，可以直接查表知道「資料該去哪裡索取」，不必重新摸索網站。

## 已收錄資料庫速查

| # | 資料庫 | 空間解析度 | 精度 | 最新年度 | 適合查 |
|---|---|---|---|---|---|
| 01a | 嘉義縣資料庫查詢平台 | **鄉鎮市**（18）+ 縣 | 整數（四捨五入） | 114 年 | 快速拉嘉義縣歷年序列、做趨勢判斷 |
| 01b | 嘉義縣**公務統計報表查詢** | **鄉鎮市**（18）+ 縣 | **原始小數** | 114 年 | **要寫進計畫書的嘉義縣數字一律走這裡** |
| 02 | 農業部統計處農業統計業務查詢 | 縣市 | 小數 2 位 | 114 年 | 全國／各縣市農地、農戶、農林漁牧生產量值、價格、農業經營、水保等 |
| 03 | 農業部漁業署漁業統計年報 | 縣市 | 小數 2 位 | 114 年 | 水產養殖面積（含休養）、漁業生產量值的原始口徑 |
| 04 | 農糧署農情報告資源網 | **鄉鎮×作物** | 小數 2 位 | 114 年 | 各鄉鎮各作物的收穫面積與產量（無製糖甘蔗、無類別合計） |

**選用原則**：嘉義縣的數字 → 01b 公務統計報表（原始小數、有鄉鎮別）；跨縣市比較或全國序列 → 02；
水產養殖口徑爭議 → 03 對帳。三者口徑不一定相同（見各資料庫的「口徑與陷阱」段落），
同一張表不要混用來源。

**已知口徑地雷**：農業部統計處 `AB04` 水產養殖面積的「養殖合計」**不含休養**，
比漁業署／縣統計年報的「總計」少一截（嘉義縣 113 年少 125.55 公頃）。

## 新增資料庫時的作法

1. 使用者給的網址若是深層查詢頁，先往上找到平台入口（麵包屑、logo 連結、網站導覽）。
2. 列舉分類代碼（本專案兩個平台都是用 query string 的數字／字母碼列舉出來的），把**整棵目錄樹**存成
   `目錄.md`（人看）＋`目錄.json`（程式用）。
3. 記錄「口徑與陷阱」：空間解析度、精度、最新年度、與其他來源的差異。
4. 能寫成 script 的就寫進 `scripts/`。
